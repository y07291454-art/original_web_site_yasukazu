# NBA Teams & Players

アメリカの地図からNBA全30チームを選び、チーム情報と選手プロフィールを見られるファンサイトです。元の木目背景、地図、チームロゴを引き継いでいます。

- 全30チームのチーム情報・アリーナ・選手カード
- チーム一覧のカンファレンス／ディビジョン／名前による絞り込み
- チーム内の選手名・背番号・ポジションによる絞り込み
- 全ページ共通のチーム・選手検索
- 選手プロフィールとNBA公式ページへのリンク
- 元の大きさで表示するマップと、スマートフォン向けナビゲーション

## 閲覧

GitHub Pagesで `index.html` を公開できます。フレームワーク、サーバー、パッケージのインストールは不要です。HTMLファイルを直接開いて閲覧することもできます。

## 情報の基準

選手データは **2026年10月16日に取得したNBA公式サイト掲載の619選手**です。キャンプ中の掲載選手を含み、レギュラーシーズンの確定登録人数を示すものではありません。移籍や背番号の変更は自動では更新されません。

- 選手情報：[NBA.com Players](https://www.nba.com/players)
- チーム一覧：[NBA.com Teams](https://www.nba.com/teams)
- 本拠地・アリーナ：各チームのNBA公式プロフィールと2026–27シーズンの公式日程
- 選手画像：NBA公式CDN。取得できない場合は共通の代替画像を表示します。

チーム情報の出典は `assets/data/nba.json` の各チームの `source_urls` に記録しています。

## 編集

データは `assets/data/nba.json`、追加した共通デザインは `assets/css/complete.css`、検索・絞り込みは `assets/js/app.js` にあります。

JSONのチーム情報や選手情報を編集した後、次のコマンドでHTMLとブラウザ用データを再生成します。

```sh
python scripts/build_pages.py
python scripts/check_site.py
node scripts/check_filters.cjs
```

ページは静的HTMLなので、JavaScriptが無効でもマップ、チーム一覧、各チームの選手一覧を閲覧できます。選手詳細と絞り込みにはJavaScriptを使います。

以前のURLを残すため、`teams.html` はレイカーズのページ、`kyrie.html` はカイリー・アービングのプロフィールとして利用できます。
